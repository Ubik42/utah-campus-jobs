# 筛选与排序规则

## 公开版原则

公开版始终保留快照中的 122 个 `Part Time` 岗位，不按某一位申请人的身份、申请日期或经历删岗。Excel 只提供客观字段和由原文提取的辅助标签，读者自行组合条件。

## 数据范围

1. 从 University of Utah Campus 招聘列表接口抓取全部分页。
2. 以 GUID 去重。
3. 仅保留接口字段 `job_type = Part Time` 的岗位。
4. 每个岗位只占一行；完整正文按字段保存，不拆成多个岗位文件。
5. 本期使用 2026-08-16 的固定快照，后续官网变化不会覆盖这个版本。

## 正文结构

Jobsyn 页面把大量小标题放在相近层级，连续阅读不方便。整理版按以下层级重建每个岗位：

1. 岗位概览；
2. 职位摘要；
3. 工作职责；
4. 最低资格；
5. 优先条件；
6. 申请说明；
7. 排班安排；
8. 折叠的英文原文。

补充信息（Additional Information）是犹他大学校级通用说明，已抽到 [shared-notices.md](shared-notices.md)，不逐岗重复。

中文和英文按相同字段对应，不合并、不概括。原页面没有提供的字段明确写“未提供”。

## 可筛选字段

### 日期

Open Date、Close Date 分列展示；Priority Review Date 仍在 JSON 中保存但不在表格展示（它不是最终截止日期）。正文若明确写明 `This posting is closed and is no longer accepting applications`，另设“页面明确关闭”标签。

表格不预设某个申请日期。使用者可以按自己的申请日筛选：开放日期不晚于申请日，截止日期不早于申请日，同时排除页面明确关闭的岗位。

### 工时

- 固定值 `15`：最低和最高工时都记为 15。
- 范围 `0-19`、`8 to 12`：第一个数字为最低工时，第二个为最高工时。
- `up to 10`、`maximum 10`、`10 hours or less`：最低工时按 0，最高工时按 10。
- `10 (up to 19)`：最低 10、最高 19。
- 无法解析或未提供：数值列留空，原文始终保留。

`0-19` 的最低工时是 0，因此若按“最低工时不大于 10”筛选，它会被保留。

### 薪资

小时工资会尽量解析为最低时薪和最高时薪，原始 Pay Rate Range 另列保存。DOE、固定总额、年薪或无法可靠判断单位的内容不强行换算。

### Federal Work-Study

- `必需`：页面字段为 Yes、标题标注 Work-Study/FWS，或正文明确出现 only、must、required、contingent 等要求。
- `可选/非必需`：正文明确写 optional、not required 或 does not require。
- `未明确要求`：规则没有找到强制或可选证据。

没有 Work-Study 资格的人可排除“必需”；已有资格的人可以保留全部类别。

### 本科生限定

逐岗记录是否明确要求 undergraduate。“否”的含义只是没有发现明确的本科生限定，不代表研究生一定符合。专业、年级、所在学院和特定项目限制仍要阅读最低资格。

### 驾照、食品证和酒类证

脚本在 Minimum Qualifications、Responsibilities、Preferences 和 Special Instructions 中查找驾驶执照、Food Handler Permit 和酒类服务认证。出现 `upon hire`、`within 30/60 days`、`ability to obtain` 等表述时标记为“入职后可取得”，其他命中标记为“明确要求/需核验”。

### 经验提示

最低资格出现明确的 `N years ... experience` 时标记“明确要求经验年限”。教育可折抵经验的岗位仍需结合专业与折抵公式人工判断。

## 排序方式

公开版默认按中文部门名、中文职位名排序，方便连续阅读同一部门的岗位。Excel 不锁定排序，读者可以改为截止日期、最低时薪、周工时、资格标签或关键词。

此前个人版使用过“最低周工时大于 10 小时的岗位在前，同组按最低时薪降序”的规则。它只是一种个人排序示例，不作为公开版默认顺序。

## 翻译规则

- 中文字段覆盖职位名、职位摘要、工作职责、最低资格、优先条件、申请说明和排班安排。
- 英文原文完整保留，与中文字段并列。
- 新增长字段由本机环境变量配置的 DeepSeek API 翻译；仓库不保存 API Key。
- 不使用公共免费翻译接口回退。DeepSeek 不可用时脚本直接报错。
- 翻译用于统一查看和检索，申请前仍应核对官网英文原文。
