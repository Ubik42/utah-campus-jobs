# 数据字典

## Excel 工作表

- `岗位检索`：短字段、日期、工时、薪资和资格标签，可直接筛选排序。
- `完整中文`：每个岗位的全部中文正文。
- `英文原文`：与中文表逐字段对应的官网原文。
- `使用说明`：数据范围、标签含义和建议用法。

## 主要字段

| 字段 | 含义 |
| --- | --- |
| 中文职位 / 英文职位 | 翻译名与官网职位名 |
| 中文部门 / 英文部门 | 清理后的部门名称 |
| 开放日期 / 截止日期 / 优先审查日 | ISO 日期；空白表示未提供或未解析 |
| 页面明确关闭 | 正文是否明确写明不再接受申请 |
| 每周标准工时 | 官网原文 |
| 最低周工时 / 最高周工时 | 从工时原文解析的数值 |
| 薪资原文 | 官网 Pay Rate Range |
| 最低时薪 / 最高时薪 | 只对可识别的小时工资填写 |
| Work-Study | 必需、可选/非必需、未明确要求 |
| 本科生限定 | 是否明确只面向本科生 |
| 驾照 / 食品证 / 酒类证 | 自动识别的要求状态 |
| 经验要求 | 最低资格是否出现明确经验年限 |
| F-1 工时风险 | 最低周工时是否超过 20 |
| 摘要 / 职责 / 最低资格 | 岗位的主要正文结构 |
| 优先条件 / 申请说明 | Preferences 与 Special Instructions |
| 排班 / 补充信息 | Work Schedule 与 Additional Information |
| GUID / Requisition Number | 岗位标识 |
| 职位链接 | 官网详情页 |

JSON 使用英文 snake_case 字段名，并保留标签证据、招聘类型和源站更新时间。
